Use of the app

Molenwind provides wind information and windmill data for millers and windmill lovers. The wind information is an aid based on weather models and may differ from reality. The miller always decides whether and how to run the mill.

Open source and sources

Molenwind's source code is open source under the MIT licence (github.com/EdCafferata/molenwind). Mill data: RCE (public domain); photos: RCE image bank (CC-BY-SA, credited); wind: KNMI via Open-Meteo (CC-BY 4.0); opening hours: OpenStreetMap contributors (ODbL).
